# LingoAgent 1.3.3

## 변경

- release version 단일 기준을 `pyproject.toml`로 맞추고 Docker image tag, runtime `LINGO_VERSION`, OCI version label과 일치시킨다.
- 배포 checkout SHA를 image build arg와 runtime `LINGO_GIT_SHA`로 전달해 OCI revision label·`/healthz`에서 확인한다.
- Compose health check와 release identity 검증은 컨테이너 내부 `/healthz`를 사용하며 host port는 공개하지 않는다.

## 검증

- `python3 -m pytest -q`
- `python3 -m compileall -q lingo tests`
- `docker compose config --quiet`
- 운영 배포 뒤 Git checkout, image tag·labels, Compose health, `/healthz` version·SHA를 대조한다.

## 배포 상태

소스 검증과 main 자동 배포 readback 뒤 근거를 기록한다.
